# Md Sohel Habib — Portfolio

Personal portfolio site. Static HTML/CSS/JS, no build step.

- **Live:** https://sohelhabib.github.io/portfolio/
- **Stack:** vanilla HTML, CSS, canvas (celestial background), SVG (chrome objects)

## Local preview
Open `index.html` in a browser, or use VS Code's **Live Server** extension.

## Structure
- `index.html` — the whole site (single file)
- `me.jpg` — profile photo (add this)
- `photos/` — photography images (add these)
- `.nojekyll` — tells GitHub Pages to skip Jekyll and serve files as-is
